## 📋 À propos

Skybound Studio accompagne indépendants, artisans et petites entreprises dans la création de leur présence digitale. Ce site présente les services, la méthodologie de travail et les réalisations du studio.

## ✨ Fonctionnalités

- **Design responsive** — Adapté à tous les écrans (mobile, tablette, desktop)
- **Formulaire de contact** — Envoi d'emails via Nodemailer et API Route Next.js
- **Animations CSS** — Transitions et animations fluides en CSS pur
- **SEO optimisé** — Métadonnées, balises Open Graph, sitemap, données structurées
- **Déploiement continu** — Hébergé et déployé automatiquement sur Vercel

## 🛠️ Stack technique

| Catégorie | Technologie |

| Framework | Next.js |

## 🚀 Installation

```bash
# Cloner le repo
git clone https://github.com/Leschaevej/Skybound-Studio.git

# Accéder au dossier
cd Skybound-Studio

# Installer les dépendances et lancer le serveur
npm start
```

## 🔧 Variables d'environnement

Créer un fichier `.env` à la racine du projet :

```env
MAIL_USER=         # Adresse email pour l'envoi
MAIL_PASSWORD=     # Mot de passe ou app password
URL=               # URL du site
```
